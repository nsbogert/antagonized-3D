A good first pass in Meshy

  1. Start with Marin · front or an ant’s single view. Download its PNG and use it as the main image input.
  2. Keep the other views beside the result to check its shape. If your workflow explicitly offers additional reference views, use the matching single-view images. Avoid feeding a whole multi-panel sheet into a single-image input.
  3. Check Marin’s face, hair, hands and boots. Check each ant for six legs, two antennae, clear leg joints and a proper narrow waist. Generated views are design guidance and may contain small inconsistencies; resolve them before rigging.
  4. Keep the crown, queen’s armor plates, flyer wings and wearable equipment separate where they need to move. The sprayer hose and transparent wings may need manual cleanup.
  5. These PNGs are concept references. The resulting 3D meshes will still need cleanup, animation rigs, textures and browser performance checks before replacing the game’s current models.

Suggested order: Marin → worker → soldier → queen → flyer → props. A defeated worker can reuse the living worker’s mesh with a folded-leg pose. Repeating the egg makes a clutch without needing another model.
